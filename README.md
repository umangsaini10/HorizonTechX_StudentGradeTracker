# Student Grade Tracker – Horizon TechX Internship

## About the Project
The Student Grade Tracker is a Java-based console application developed as part of the Horizon TechX Java Programming Internship.

The application helps manage student academic records by storing student marks and generating a performance summary. It calculates the average, highest, and lowest scores to provide a clear overview of academic performance.

## Features
- Store and manage student marks.
- Calculate average marks.
- Identify the highest score.
- Identify the lowest score.
- Display a detailed performance summary.
- Simple and user-friendly console interface.

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Arrays / ArrayList
- Core Java

## Concepts Implemented
- Classes and Objects
- Methods
- Loops and Conditional Statements
- Arrays / ArrayList
- Data Handling and Calculations

## How to Run
1. Clone or download this repository.
2. Open the project in Eclipse, IntelliJ IDEA, or another Java IDE.
3. Locate the main Java class.
4. Run the application.
